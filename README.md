# Muhammad Zohaib Abbas — Portfolio

A responsive, static portfolio website. Open `index.html` in a browser to preview it, or upload this folder to any static web host.

## Edit the content

All page text, styling, and links are in `index.html`. The stylesheet is inside the `<style>` element near the top of the file. The page loads the Manrope and DM Mono fonts from Google Fonts; system fonts are used if they are unavailable.

## Publish

For Vercel, Netlify, GitHub Pages, or another static host, deploy the directory containing `index.html`. There is no build command or dependency installation.
